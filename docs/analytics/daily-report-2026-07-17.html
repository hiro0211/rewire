横断分析
  • ASC Downloads 4 に対し GA4 new_users 5・first_open 5 と整合。一方 ASC の Trial 0 と RevenueCat Active Trials 3 が食い違い、ASC 側の集計遅延か別日起票の可能性。
  • GA4 paywall_viewed 5 全てが dismissed、purchase_initiated 1 は failed。ASC の paid_conversions 1 は Unknown チャネル由来で、アプリ内導線とは別経路の可能性が高い。
  • GA4 D1 継続率 1.8%（cohort 54）に対し RevenueCat Active Users 61 / New Customers 54（P28D）。獲得は回っているが翌日定着がほぼ無く、churn 22 件の主因と推測される。
改善提案
  • 今日(即実装): paywall の dismiss 率100%を受け、`components/paywall/Default.tsx` の CTA 文言をトライアル訴求（無料期間の明示）に差し替える。
  • 今週(着手): purchase_failed の原因を切り分けるため、失敗理由コードを logEvent パラメータに追加（TDD でロガーのテストから）。あわせて D1 継続率改善のため onboarding 完了直後の通知スケジュール導線を検証。
  • 今月(計画): ASO の A/B（Product Page Optimization）で page_view_rate 5.8%→10% を目標にアイコン・サブタイトル2案をテスト。同時に breathing/panic 系イベントが本番ビルドで確実に飛ぶことを実機検証し、SOS フロー計測を確立する。

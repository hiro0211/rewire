## 概要 / Description（4000字以内 / 1383字使用）

```
自分を嫌いになる夜を、終わりにしませんか？

「副業で稼いで自由になりたい！」
「出世して圧倒的な結果を出したい！」
「自信に満ちた魅力的な男になりたい！」　

そう固く決心したはずなのに、気づけばポルノサイトを巡回している。

たった数分の快楽のために「最高の1本」を探して何時間も無駄にし、行為の直後に強烈な自己嫌悪に襲われる。
「また貴重な時間をドブに捨ててしまった…」

世の中の男性の9割が、こうして本来、仕事や副業に使うべきエネルギーと集中力を「ポルノ」に奪われ続けています。
何度やめようと誓ってブックマークを消しても、数日後にはまたお気に入り動画が復活している。
それは、あなたの意志が弱いからではありません。

脳の報酬系がハックされているからです。気合いや根性で「本能」には勝てません。
だからこそ、意志力に頼らず「脳の回路を再配線する」ために開発されたのが、この『Rewire（リワイア）』です。

▼ こんな悩みを解決します

・SNSからポルノにたどり着く悪循環を断ち切りたい
・何度も失敗して、自分を信じられなくなった
・ポルノ視聴後の後悔で、副業や学習への集中力もやる気も消える

▼ 主な機能

【毎日の振り返り】
ポルノの視聴有無、誘惑レベル、ストレス、生活の質を毎日記録。メモも残せます。自分がいつ、どんな状況で誘惑に弱くなるのか、行動パターンが見えてきます。

【連続クリア日数（ストリーク）】
ポルノを見なかった日を積み上げるカウンター。ホーム画面で今日のストリークをひと目で確認。7日、14日、30日、90日——目標に向かって記録を伸ばす達成感が、続ける力になります。

【深呼吸エクササイズ】
衝動が来たらホーム画面のポルノを見たくなったらボタンをワンタップ。アニメーションと振動ガイドに従って深呼吸するだけで、衝動の波をやり過ごせます。目を閉じたままでも吸う・吐くのタイミングがわかります。

【カレンダー＆履歴】
達成日は緑、リセット日は赤。カレンダー表示とリスト表示を切り替えて記録を一覧できます。

【実績バッジ】
ストリークの節目で実績バッジを獲得。タイムラインで自分の成長の軌跡を振り返れます。

【リカバリーサポート】
もし見てしまっても、大丈夫。「何が引き金だったか」を振り返り、次のアクションにつなげましょう。

【ポルノブロッカー】
Safariのアダルトサイトへのアクセスを自動ブロック。ステップごとのガイドで簡単に設定できます。

【ウィジェット】
ホーム画面にストリークウィジェットを設置。アプリを開かなくても今日の記録が目に入ります。

▼ プライバシー
すべてのデータはデバイスにのみ保存。外部サーバーへの送信は一切ありません。

▼ サブスクリプションについて
・お支払いはApple IDアカウントに請求されます
・現在の期間終了の24時間前までにキャンセルしない限り自動更新されます
・管理・解約はiPhoneの設定 → サブスクリプションから可能です

利用規約：https://hiro0211.github.io/rewire-support/#terms
プライバシーポリシー：https://hiro0211.github.io/rewire-support/#privacy
```

# Safari ブロックページ — 自然な日本語版 コピー5案

> **目的：** 翻訳調を排した、ネイティブが声に出して読んでも違和感のないコピー5案を提示する。
>
> **最終更新：** 2026-04-21

---

## 0. 意訳のコツ（リサーチ結果サマリー）

英和翻訳・日本語UXライティングのベストプラクティス調査で見えてきた「不自然さの原因」と「意訳のルール」。

### 0.1 翻訳調を生む7つの癖

| # | 英語の癖 | 日本語での不自然さ | 直し方 |
|---|---------|-----------------|-------|
| 1 | 無生物主語（Rewire blocked this site） | 「Rewire はブロックしました」 | 主語を省略 or ユーザー視点に転換 |
| 2 | 所有格の明示（your urge, your feeling） | 「あなたの衝動」「あなたの気持ち」 | 「あなたの」を削る |
| 3 | 受動態＋過去形 | 「〜されました」 | 能動態・現在形で語る |
| 4 | to不定詞（to protect you） | 「〜を守るために」 | 「〜のために」を削る |
| 5 | 名詞化（do a reflection） | 「振り返りをしてみませんか」 | 動詞に戻す（振り返る） |
| 6 | 長い修飾（the site you tried to access） | 「あなたがアクセスしようとしたサイト」 | 文脈で省略 |
| 7 | 丁寧語の過剰（丁寧にしようとする直訳） | 「〜いたしました」「〜おります」 | 「〜しました」「〜います」で十分 |

### 0.2 日本語コピーの3原則

1. **13文字ルール**: 人間の瞬読限界。H1は13文字以内に収める
2. **体言止めでリズム**: 文末を名詞で止めて余韻と強調を作る
3. **口語の呼吸**: 読点「、」で息継ぎ。書き言葉より話しかけるリズム

### 0.3 現行コピーを7原則で添削

```
現行：衝動に気づきました
      Rewire はあなたを守るためにこのサイトをブロックしました。
      今の気持ちを振り返ってみませんか？
```

| 問題箇所 | 違反原則 |
|---------|---------|
| 「気づきました」 | 主語が曖昧（誰が？） |
| 「Rewire は」 | 無生物主語 |
| 「あなたを」 | 所有格・目的語の直訳 |
| 「守るために」 | to不定詞直訳 |
| 「ブロックしました」 | 過去形の硬さ＋パターナル |
| 「気持ちを振り返ってみませんか」 | 名詞化＋長い＋間延び |

## 1. 自然な日本語版 5案

### 案A　自律フレーム

```
止めるって、決めたはず。

あのときの自分が、
いまの自分を止めている。

[  Rewire を開く  ]

通知からも開けます
```

**この書き方の意図**

- 主語「あなた」「Rewire」をすべて省略
- 「決めたはず」の文末で確認形にし、押し付けずに問いかける
- 「あのとき」「いまの」で時制を対比し、ユーザー自身の中の対話にする
- 「止めている」の現在進行形で、過去の意志が今も効いていることを示す

**比較 — 直訳調だとこうなる**

> あなた自身が以前設定したルールに基づき、このサイトへのアクセスを停止しました。

---

### 案B　時間投資フレーム

```
この30分、もったいなくない？

奪われるのは、
明日の集中力。

[  集中を取り戻す  ]

通知からも開けます
```

**この書き方の意図**

- 「この30分」で具体。数字は瞬時に認知される
- 「もったいなくない？」の反語で、説教ではなく同僚の声かけトーン
- 「奪われるのは〜集中力」の体言止めで強い余韻
- プロダクト原則「ポルノ断ちは手段、自己成長が目的」に完全一致

**比較 — 直訳調だとこうなる**

> これから30分をこのコンテンツに費やすことで、あなたは明日の集中力を失います。

---

### 案C　グラウンディングフレーム

```
とりあえず、深呼吸。

3分だけ Rewire と。
決めるのは、そのあと。

[  3分だけ付き合う  ]

通知からも開けます
```

**この書き方の意図**

- H1「とりあえず、深呼吸。」で6文字。認知負荷最小
- 「3分だけ Rewire と。」の体言止めで軽やかさと余韻
- 「決めるのは、そのあと。」の語順後倒しで自然な呼吸
- 衝動ピーク時（前頭前皮質が弱い）に最も届く低負荷設計

**比較 — 直訳調だとこうなる**

> まず深呼吸をしてください。その後3分間だけRewireを使ってみて、それから判断しても遅くありません。

---

### 案D　脳科学フレーム

```
その欲、20分で引く。

見なくても消える。ちゃんと。

[  20分、やり過ごす  ]

通知からも開けます
```

**この書き方の意図**

- 「その欲」の指示詞で、ユーザー自身の中にある衝動として客観化
- 「20分で引く」の体言止め＋口語で、科学的事実を親しく伝える
- 「ちゃんと。」を後置することで、断定しつつ親密さを出す
- Urge Surfing（波はピークを越えて消える）の原理を翻訳調なく伝える

**比較 — 直訳調だとこうなる**

> 衝動のピークは20分で過ぎることが科学的に証明されています。視聴しなくても必ず消退します。

---

### 案E　アイデンティティフレーム

```
昨日の自分で、終わりにする。

ここで戻れば、今日の勝ち。

[  切り替える  ]

通知からも開けます
```

**この書き方の意図**

- 既存ブランドタグライン「昨日までの自分は、もういい」を受け継ぐ
- 「終わりにする」の宣言形で、ユーザー自身の意思として語る
- 「ここで戻れば、今日の勝ち」の体言止めでゲーム的達成感
- 「切り替える」の CTA で、アプリ起動後の体験とトーンが揃う

**比較 — 直訳調だとこうなる**

> 過去の自分自身を終わらせましょう。ここで引き返すことで、あなたは今日の勝利を手にします。

## 4. 実装候補の書式（ブロックページ HTML 差し替え用）

案A をベースにした `blocked.html` の差し替えテンプレート例:

```html
<div class="container">
  <img src="icons/app-icon.png" alt="Rewire" class="app-icon" />
  <h1>止めるって、決めたはず。</h1>
  <p>あのときの自分が、<br/>いまの自分を止めている。</p>
  <button id="rewire-open" type="button">Rewire を開く</button>
  <p class="subtext">通知からも開けます</p>
</div>
```

文字数が減ったため、現行の `blocked.css` の余白設計と整合する。変更箇所は `<h1>` と `<p>` のテキストのみ。

## 5. 使い分けのガイドライン

- **迷ったら案A**：最も普遍的、外れが少ない
- **夜22時以降の強介入には案B**：時間的損失の文脈が最も効く時間帯
- **衝動ピークを想定するなら案C**：認知負荷最小
- **科学リテラシーの高いユーザー層には案D**：オンボーディングで Urge Surfing 教育済みなら刺さる
- **30日以上の継続ユーザーには案E**：ブランドへの没入度が高い層で最大効果

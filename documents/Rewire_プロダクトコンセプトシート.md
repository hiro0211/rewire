## 1. プロダクトビジョン

### 1.1 一言で

> **脳を再配線し、人生を前に進めるアプリ。**

### 1.2 コンセプトステートメント

Rewire は、ポルノをやめたい日本人男性が、ドーパミンに支配された行動パターンを科学的に書き換え、節約した精神リソースをキャリア・副業・自己成長に再投資できる状態をつくるアプリ。

ポルノをやめること自体は目的ではない。その先にある **「自分をコントロールできている実感（自己効力感）」と「自分との約束を守れる人間になること」** がゴール。

### 1.3 プロダクト原則（守るべき判断基準）

| # | 原則 | 意味 |
|---|------|------|
| 1 | **衝動を呼吸で受け流す** | 意志力に頼らない。衝動の波を深呼吸とSOS導線で物理的にやり過ごす |
| 2 | **見える化で自覚させる** | 毎日の振り返りと進捗ダッシュボードで、自分のパターンを数値化する |
| 3 | **ポルノ断ちは手段、自己成長が目的** | 「やめる」ではなく「前に進む」。キャリア・副業・集中力の文脈で設計する |
| 4 | **弱者扱いしない** | 依存症、治療、回復といった言葉は使わない。自分を律して前に進む人向け |
| 5 | **マスターベーションは否定しない** | ポルノ視聴に特化する。自然な性欲まで抑圧する設計にしない |

## 4. 課題の構造分析 — ドーパミンチェーン

### 4.1 ポルノに到達する行動パターン

中村 拓也がポルノにたどり着くパターンは、ドーパミンを求めて段階的に刺激がエスカレーションする連鎖で整理できる。

```
[Stage 0] ストレス・退屈・疲労
    │
    │  ドーパミンを求めてスマホに手を伸ばす
    ▼
[Stage 1] 低刺激メディアで満たそうとする（ゲーム、Netflix、SNS）
    │
    │  刺激に慣れ、物足りなさが生まれる
    ▼
[Stage 2] より強い刺激を求め、Safari でアダルトを検索する衝動が立ち上がる
    │
    ▼
[Stage 3] Safari でアダルトサイトにアクセスしようとする
    │
    ▼
[Stage 4] ポルノサイトで視聴
    │
    ▼
[Stage 5] 視聴後の後悔・集中力壊滅・自己効力感低下
```

### 4.2 既存ソリューションの限界

| ソリューション | 介入ポイント | 限界 |
|--------------|-------------|------|
| Safariアダルトブロック（iOS標準） | Stage 3〜4 | 自分でパスコード入力して解除可能。衝動下では簡単に解除する |
| Brainbuddy | Stage 4（衝動時の呼吸）＋ 記録 | 英語圏向けで日本人ユーザー向けの設計・トーンがない |
| iOSスクリーンタイム | Stage 3 | 汎用ブロック。アダルト特化ではなく、ブロック回避のしやすさが課題 |

### 4.3 Rewire の介入設計 — 2層防御 + リカバリー

```
[Layer 1] Safari Web Extension     ← Stage 3〜4 で介入（自動ブロック＋/panic誘導）
    ↓ 衝動が収まらない場合
[Layer 2] SOSボタン → 呼吸セッション ← Stage 2〜4 で介入（ユーザー自身が起動）
    ↓ それでも見てしまった場合
[Recovery] リカバリーフロー + Reflection Sheet ← Stage 5 で回収
```

**差別化のポイント：** iOS標準ブロックや英語圏アプリでは、ブロック突破後の受け皿が用意されていない。Rewire は「ブロックページ → ローカル通知 → /panic 画面 → 呼吸セッション」という連続したユーザー導線を持ち、**衝動を呼吸でやり過ごした後、Reflection Sheet で自覚につなげる**ところまでを1つの体験として設計している。

## 5. 利用シーン（When / Where / How）

### 5.1 衝動に襲われたときのシーン

| シーン | 時間帯 | 状態 | Rewire の介入 |
|--------|--------|------|-------------|

### 6.3 Rewire が作る状態変化の本質

```
Before: 「ポルノを見たくないのに見てしまう自分」
                        ↓

```

これはポルノの話ではない。**自己効力感の回復の話**である。ポルノ断ちはそのための最も効果的なトレーニングであり、Rewire はそのトレーニングを科学的に支援するツールである。

## 7. 科学的根拠に基づく介入設計

### 7.1 Layer 1: 刺激制御（Stimulus Control）の科学的根拠

**根拠①：CBTベースの刺激制御**

認知行動療法（CBT）における刺激制御の原則では、望ましくない刺激をアクセス困難にし、代替行動を用意することで衝動行動を減らす。

Rewire への応用：Safari Web Extension がアダルトドメインを自動検出してブロックページに置換する。さらにブロックページからローカル通知が発火し、ユーザーを `/panic` 画面に誘導することで、衝動 → ポルノ視聴 の経路を物理的に遮断する。

### 7.2 Layer 2: 衝動介入の科学的根拠

**根拠②：Urge Surfing（衝動サーフィン）**

依存症研究の先駆者 Alan Marlatt 博士が提唱した技法。衝動を「波」として観察し、戦わずにやり過ごす。研究によると、衝動は対処しなくても20〜30分でピークを越えて自然に減衰する。衝動に対して好奇心を持って観察する態度を取ると、感情的反応性が低下し、衝動への耐性が高まる。

Rewire への応用：ダッシュボードに常設された SOSボタンから1タップで `/panic` 画面へ移動し、そのまま呼吸セッション（`/breathing`）に入る。呼吸に没入することで、衝動と行動の間に「間（ま）」を作り、ハビットループ（トリガー → 行動 → 報酬）を中断する。

**根拠③：Implementation Intentions（実行意図）**

Gollwitzer（1999）が提唱した「if-then プラン」。「もし〜の状況になったら、〜する」を事前に決めておくことで、状況と代替行動の連想が自動化され、習慣的反応を上書きできる。

Rewire への応用：オンボーディングで「衝動が来たら SOS ボタンを押す」という行動ルールを体験として定着させる。これにより「衝動 → ポルノ」の自動反応を「衝動 → SOS → 呼吸」に書き換える。

### 7.3 Layer 3: 自己認識の科学的根拠

**根拠④：セルフモニタリング効果**

行動科学では、自分の行動を記録するだけで行動が改善する「セルフモニタリング効果」が広く知られている。記録の負荷が低いほど継続しやすい。

Rewire への応用：Reflection Sheet は「視聴有無」「誘惑レベル」の2項目のみに絞り、30秒で完了できる設計とした。Bottom Sheet 形式で摩擦を最小化し、通知タップからそのまま入力できる導線を用意している。

### 7.4 回復の科学的タイムライン

| 期間 | 変化 |
|------|------|
| 最初の1〜2週間 | 最も衝動が強い。睡眠・気分が不安定になりやすい |
| 3〜6週間 | トリガーの力が弱まり始める。新しいルーティンが定着し始める |
| 2〜3ヶ月 | 注意力・エネルギー・気分がより安定する |
| 6〜12ヶ月 | 突発的な衝動が大幅に減少。アイデンティティの変化（「ポルノを見ない人」としての自己認識） |

これは中村 拓也の「13日の壁」を説明する。最初の2週間が最も困難であり、そこを突破できれば3〜6週間目から急速に楽になる。Rewire は最初の2週間を生き延びるための強力な支援ツールとして機能する。

## 10. 課金トリガー設計（なぜユーザーはお金を払うのか）

### 10.1 課金判断の心理

中村 拓也が課金するのは「機能に払う」のではない。**「13日の壁を越えた自分」に投資する**のである。

| 心理 | 具体的なモーメント |
|------|------------------|
| 「今までと違う」 | Safari Web Extension が衝動時のアクセスを止め、そのまま呼吸セッションまで導いてくれた瞬間 |
| 「このまま続ければ変われる」 | 呼吸セッションで衝動をやり過ごせた直後の承認体験 |
| 「もっと自分を律したい」 | 7日ストリーク達成時に、継続の価値が実感できたとき |
| 「このバッジを揃えたい」 | Neural Cosmos の次のバッジまでの距離を見て、ゴールが具体化したとき |

### 10.2 Free → Pro 転換ポイント

| タイミング | 提示内容 |
|-----------|---------|
| オンボーディング完了直後 | 目標設定・ベネフィット訴求が完了したタイミングで Pro を提示 |
| 7日ストリーク達成時 | 「7日間達成。Pro で継続をサポートしませんか？」 |
| Reflection Sheet 完了後 | 振り返りデータが溜まるにつれて、より深い自己理解のために Pro を提示 |
| ポルノ視聴してしまった直後 | **絶対に課金誘導しない。** リカバリー中のユーザーに売り込みは禁止 |

### 10.3 価格設計（現行）

Rewire Pro は RevenueCat を介して課金を管理し、`PaywallDefault` の単一ペイウォールで提示する。

| プラン | 価格 | 月あたり換算 |
|--------|------|-------------|
| Monthly | ¥680/月 | ¥680 |
| Yearly | ¥5,400/年 | 約¥450 |

**設計意図：**

- Yearly を月あたり¥450（Monthly の約66%）に設定し、長期継続にインセンティブを置く
- ペイウォールは `PaywallDefault` 1種類のみを運用し、導線を単純化してユーザーの認知負荷を下げる
- オンボーディング後と、使用中の節目タイミング（ストリーク達成など）で提示する

> **補足：** 過去に割引ペイウォール（¥2,500/年）と無料トライアル付きペイウォールを3段階で提示する設計を実装したが、App Store Review Guideline 5.6 への対応として現在は休止中。再開する場合はガイドラインの要件を満たす形で再設計する。
